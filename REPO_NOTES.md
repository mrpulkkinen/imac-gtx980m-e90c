# Repository publishing notes

Suggested repository name:

`imac12-1-gtx980m-e90c`

Suggested description:

> Experimental Linux flashing and UEFI boot notes for an MSI E90C GTX 980M in a 21.5-inch 2011 iMac (iMac12,1).

Before publishing:

1. Add exact canonical links to the m0bil GTX 980M R1_EG post, Acidanthera EnableGop documentation, and NVIDIA DCB/BIT specifications.
2. Do not redistribute NVIDIA NVFlash unless its license explicitly permits it.
3. Do not redistribute third-party ROMs without permission. Prefer hashes plus links to their original source.
4. Decide whether to publish your own experimental TEST1/TEST2 patches. If you do, retain the warnings that they were tested only on `10DE:13D7:1462:1129`, Board ID E90C.
5. Update the Windows section after the internal-disk installation/boot test.

No software license file is included yet because documentation licensing and redistribution rights for firmware/tooling should be chosen deliberately before publication.
